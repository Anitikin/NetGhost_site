# NetGhost — Правовая база по информационной безопасности

Публичная база знаний нормативно-правовых актов и методических материалов 
в сфере информационной безопасности Российской Федерации.

**Сайт:** https://anitikin.github.io/NetGhost_site/

## О проекте

NetGhost — открытый ресурс для всех, кто работает или изучает сферу ИБ. 
Здесь собраны актуальные НПА, ГОСТы и методические рекомендации в удобном 
формате с возможностью быстрого поиска.

## Что есть на сайте

- Конституция Российской Федерации
- Уголовный кодекс РФ
- Федеральный закон РФ
- Административный кодекс КоАП РФ
- Гражданский кодекс РФ
- Постановления Правительства
- Приказы
- Указы Президента
- Международные стандарты и ГОСТы
- Информационные письма
- Методические рекомендации
- Официальные разъяснения
- Правовой ассистент на базе ИИ

## ИИ-ассистент

На сайте встроен правовой ассистент на базе ИИ.

Он умеет:
- Найти нужный закон, статью или ГОСТ
- Объяснить что грозит за конкретные действия в сфере ИБ
- Разобрать сложный текст документа простым языком
- Объяснить термины информационной безопасности

Просто нажмите кнопку **💬 Правовой ассистент** в правом нижнем углу сайта.

## Технологии

- [VitePress](https://vitepress.dev/) — генератор статических сайтов
- GitHub Pages — хостинг
- ИИ-ассистент на базе LLM API
