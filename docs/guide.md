# Руководство пользователя NetGhost

Интерфейс сайта спроектирован так, чтобы им мог пользоваться каждый. Система не требует установки, стабильно работает на компьютерах через любой браузер и адаптируется под любой экран.

## Навигация по базе законов 

Для удобства вся нормативно-правовая база разделена по категориям: от Конституции и Федеральных законов до приказов регуляторов (ФСТЭК/ФСБ) и ГОСТов. Вам не придется долго искать нужный массив данных — все основные блоки вынесены прямо на главную страницу.

**Выбор и просмотр документа:**

1. Нажмите на подходящий блок на главной странице, и в левой части экрана откроется список всех доступных документов.
2. Кликните на нужный закон из списка, чтобы открыть его текст в центре экрана.
3. Переходите между документами этой же категории с помощью левого бокового меню.
4. Нажмите на название сайта в верхнем левом углу, чтобы сбросить поиск и вернуться на главную страницу.

## Работа с ИИ-ассистентом

Если вы не знаете, в каком именно законе искать ответ, воспользуйтесь умным помощником. Иконка чата доступна на каждой странице сайта.

**Как устроен процесс:**

+ • Откройте чат кликом по иконке и напишите свой вопрос обычными словами, после чего нажмите Enter.
+ • ИИ сам поймет контекст проблемы и найдет нужные требования, даже если вы не знаете номеров статей.
+ • Помощника можно попросить расшифровать сложный юридический термин или пункт закона простым языком.
+ • Ассистент ищет ответы только по загруженным на сайт законам и всегда подкрепляет свой ответ ссылкой на реальную статью, исключая выдуманные факты.
